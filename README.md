# Data-Visualization-Silk-Road
 
This repository contains a data visualization project focused on the Silk Road trade route. The project includes several CSV files containing data related to categories, items, prices, and feedback. Additionally, there are two Jupyter Notebook files, one named "streamlit (1).ipynb" and another named "streamlit_appp.py", which likely contain the code for the data visualization application.

### Main Function Points
- Data analysis and visualization of the Silk Road trade route
- Exploration of categories, items, prices, and feedback data
- Development of a data visualization application using Streamlit

### Technology Stack
- Python
- Pandas
- Streamlit
